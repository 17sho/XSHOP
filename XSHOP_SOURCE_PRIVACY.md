# XSHOP source snapshot

This source-only edition replaces operator-specific names, domains, email identifiers and logos with XSHOP and reserved example fixtures. Example endpoints are not live configuration. Original project GPL license and upstream notices remain unchanged.

GitHub workflows are retained as inactive source in `source-workflows/`; do not enable automation without separate review. No original Git history, runtime configuration, customer database, credentials or deployment data is included.

The generic browser checkout-storage key intentionally does not migrate operator-branded browser state. This edition is a fresh installation source, not a live-site upgrade.
